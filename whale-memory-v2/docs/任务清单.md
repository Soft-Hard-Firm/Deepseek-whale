## P0 · 能跑起来

### T1 · 存储层

**范围**：`lib/store.js`——读写 `记忆.json`、追加 `原文/*.jsonl`、原子替换、备份。

**依赖**：无

**DoD**
- [x] 读：文件不存在返回空库，不抛错
- [x] 写：先写 `.tmp` 再 rename，中断不产生半截文件
- [x] 坏文件不静默覆盖，转备份并报 `store_corrupt`
- [x] 原文追加不修改已有行
- [x] 写前取锁，取不到返回 `lock_held`（PRD H1）
- [x] 落盘完成才返回成功（PRD H3 的损坏侧）
- [x] 损坏文件改名保留，从备份恢复

**验证**
```bash
npm test -- tests/unit/store.test.js
```
