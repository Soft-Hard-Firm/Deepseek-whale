# whale-memory-v2 · 工程规范

## 1. 目录

```
whale-memory-v2/
  index.js              插件入口，只做装配
  lib/
    store.js            文件读写、原子替换、备份
    model.js            条目结构、状态转移、校验
    retrieve.js         分词、稀有度、评分、选条
    decay.js            新鲜度、压缩、淘汰
    inject.js           context/section 注册与渲染
    tools.js            工具定义与参数校验
    migrate.js          旧库转换
  tests/
    unit/               纯函数单测
    accept/             验收用例（对应 PRD §2）
    fixtures/           测试数据
  docs/                 文档（受保护，见 AGENTS.md）
  package.json
```

**约束**

- `index.js` 不写业务逻辑，只装配
- `lib/` 之间不允许循环依赖
- `retrieve.js` 与 `decay.js` 互不依赖
- 每个模块只导出一个命名空间，不导出内部函数

## 2. 命名

| 类别 | 规则 | 例 |
|---|---|---|
| 变量、函数 | 小驼峰 | `loadStore` |
| 常量 | 全大写下划线 | `MAX_TEXT_LEN` |
| 类 | 大驼峰 | `Budget` |
| 文件 | 小写短横线 | `store.js` |
| 测试文件 | 与被测同名 + `.test.js` | `store.test.js` |

**字段名保持与数据契约一致**，不重命名：`alpha` 不写成 `importance`，`beta` 不写成 `confidence`。

## 3. 代码约束

1. 无外部运行时依赖。只用 Node 内置模块。
2. 不写 `console.log` 做日志，用统一的 `log(level, msg)`。
3. 所有文件写入用「临时文件 + rename」原子替换。
4. 所有外部输入（工具参数）先校验，再进业务。
5. 不捕获后忽略异常；捕获就要处理或重抛。
6. 定时器回调一律 `try/catch` 包住，不让异常冒到进程。
7. 截断文本按码点，不按 UTF-16 单元。
8. 写文件一律 UTF-8 无 BOM。

## 4. 测试

| 层 | 要求 |
|---|---|
| 单测 | 每个 `lib/` 模块至少覆盖：正常路径 + 边界 + 错误输入 |
| 验收 | PRD §2 每条一个用例，文件放 `tests/accept/` |
| 回归 | 修 bug 必须补一条能复现该 bug 的测试 |

**测试不得依赖真实时钟**。时间一律注入（`now` 参数或可替换的时钟函数）。

**测试不得依赖网络与模型调用**。需要模型输出的地方用固定样本文件。

## 5. 命令

```bash
npm test              # 全部单测
npm run test:accept   # 验收用例
npm run check         # lint + typecheck
npm run backup        # 手动备份当前库
```

## 6. 提交

- 一次提交只做一件事
- 提交信息：`<type>: <一句话>`，type 取 `feat|fix|refactor|test|docs|chore`
- 提交前必须 `npm run check && npm test` 通过
- 不提交密钥、不提交 `node_modules`、不提交本地数据目录

## 7. 依赖管理

新增依赖需同时满足：

1. 有明确的必要性说明
2. 无原生编译
3. 许可证为 MIT / Apache-2.0 / ISC

本项目目标为零运行时依赖。

## 8. 文档维护

- `docs/` 归主代理维护，子代理只提建议
- 文档描述架构，不描述实现细节
- 文档不记录变更历史
- 改架构必须同步改 `docs/`
